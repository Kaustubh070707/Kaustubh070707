# 💫 About Me:
* 🔭 **I'm currently working on** — two AI systems I built end to end. One is a chatbot that answers only from my own documents — it cites every fact and says "not found" instead of guessing (it scores 29 out of 30 on my own test set and runs live). The other is a 7B open model I fine-tuned to summarize Indian legal judgments in a fixed format, which improved its score from 0.324 to 0.404.<br>* 👯 **I'm looking to collaborate on** — applied AI projects where testing is taken seriously. I like work that starts with "how will we know it's good" — a labeled test set, a baseline number, and a before/after table. If your project measures retrieval quality, refusal rates, or answer faithfulness, that's my kind of work. I work mostly in Python with PyTorch, Transformers, and LangGraph.<br>* 🤝 **I'm looking for help with** — two things I'm growing into: re-ranking search results at scale, and running pgvector in production past toy-sized data. My retrieval works well on small corpora (keyword plus AI-embedding search combined), so ranking quality and serving vectors at real size are the next hills. If you've done either, I'd love to learn how.<br>* 🌱 **I'm currently learning** — orchestration with LangGraph (planner-worker agents, checkpoints, tool calling) and MLOps basics like experiment tracking and drift monitoring. I also keep sharpening CI/CD — my pipelines lint, test, scan for vulnerabilities, and deploy with automatic rollback.<br>* 💬 **Ask me about** — building Python backends with FastAPI that fail safely, shrinking Docker images (mine went from 1.9GB to under 500MB), writing eval harnesses with refusal tests, or pipelines with vulnerability scans and rollback proofs. Happy to walk through any of it.<br>* ⚡ **Fun fact** — some of my hardest bugs were tiny things: a YAML colon that broke parsing, a capital letter my container registry rejected, and program output silently flowing into a dead background thread for three whole test runs. I learned to trust evals and logs more than my eyes.
